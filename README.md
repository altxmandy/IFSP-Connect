nome do projeto: IFSP-Connect

autor: Amanda Novais Cunha

curso: Engenharia da Computação 2º Semestre

objetivo do IFSP Connect: O IFSP Connect é um website fictício criado para acompanhar sua evolução durante o curso de Desenvolvimento
Front-End. A cada missão, novas funcionalidades serão adicionadas ao projeto, permitindo que você aplique, na prática, os conceitos estudados.


tecnologias que serão utilizadas (HTML, CSS e JavaScript): Ao final das três unidades, o IFSP Connect terá evoluído para uma aplicação web completa, contendo páginas
estruturadas em HTML, estilos desenvolvidos com CSS e funcionalidades interativas implementadas com JavaScript.
