Bem-vindo ao IFSP-Connect!

Olá! Meu nome é Amanda Novais, faço Engenharia da Computação no Instituto Federal de São Paulo de Guarulhos (IFSP - GRU). Este é meu primeiro projeto na aula de Front-End nesta instituição e, por meio dele, poderei acompanhar minha evolução durante as aulas.

Objetivo do sistema:

O IFSP-Connect é um website criado para acompanhar minha evolução durante o curso de Desenvolvimento Front-End. A cada missão, novas funcionalidades serão adicionadas ao projeto, permitindo que eu coloque em prática os conceitos estudados.

Como o sistema será desenvolvido:

Ao final das três unidades, o IFSP Connect terá evoluído para uma aplicação web completa, contendo páginas estruturadas em HTML, estilos desenvolvidos com CSS e funcionalidades interativas implementadas com JavaScript. Alguns dos recursos que serão adicionados ao longo do desenvolvimento são: Página inicial (Home), Página sobre a instituição, Catálogo de cursos, Agenda de eventos, Galeria de imagens, Formulário de contato, Área de notícias, Interface responsiva, Componentes interativos e Validação de formulários.

Proposta do projeto:

A proposta do IFSP-Connect é desenvolver um sistema ao longo das aulas, adicionando novas funcionalidades conforme os conteúdos forem aprendidos.

Durante o desenvolvimento, serão utilizados diferentes conceitos de HTML, CSS e JavaScript, permitindo colocar em prática o que foi aprendido nas aulas.

Além disso, o IFSP-Connect servirá como um portfólio para registrar os conhecimentos adquiridos ao longo do curso.

Desenvolvido por: Amanda Novais Cunha - Engenharia da Computação - Instituto Federal de São Paulo (IFSP - Guarulhos)
